ENS Data Challenge

Objective

This project is part of an ENS data challenge proposed by Enedis and focuses on the reconstruction of missing values in electricity consumption time series collected by Linky smart meters.

The objective is to detect these missing values and reconstruct complete and consistent time series. Model performance is evaluated using the Mean Absolute Error (MAE), computed only on the missing points.

Tools & Languages
  • Python
  • Pandas
  • scikit-learn

Project Description

This report presents a state-of-the-art overview of the main approaches that can be used to address the challenge. In parallel, baseline reconstruction approaches such as k-Nearest Neighbors (k-NN) and Matrix Completion have been explored.

Data Preprocessing

A dedicated Python notebook was developed to preprocess the electricity consumption time series before modeling. The notebook handles data loading, detection of missing values, alignment of daily consumption curves, and construction of clean inputs for reconstruction algorithms.

  • Identification and masking of missing segments in daily time series
  • Filtering and validation of corrupted or incomplete curves
  • Reshaping and normalization of data for model compatibility

Matrix Completion Code

A matrix completion approach based on low-rank approximation was implemented to reconstruct missing values in electricity consumption time series, leveraging correlations across thousands of consumption profiles. (Ranked 37th out of 120 with this code)
