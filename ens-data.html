📊 ENS Data Challenge

Objective

This project is part of an ENS data challenge proposed by Enedis and focuses on the reconstruction of missing values in electricity consumption time series collected by Linky smart meters. The dataset contains synthetic daily consumption curves, some of which include missing segments caused by transmission or storage issues.

The objective is to detect these missing values and reconstruct complete and consistent time series. Model performance is evaluated using the Mean Absolute Error (MAE), computed only on the missing points.

Tools & Languages
  • Python
  • Pandas
  • scikit-learn

Project Description

At the current stage, we are finalizing a dedicated notebook for data cleaning and sorting, ensuring consistent preprocessing and reliable feature construction. In parallel, we are actively working on k-Nearest Neighbors (k-NN) models to establish baseline performance and guide future modelling choices.
